# 📝 Task Manager

## 📌 Project Overview
The **Task Manager** is a productivity application designed to help users efficiently organize, track, and manage their daily tasks. The system allows users to create, update, and delete tasks while maintaining a clear overview of pending and completed activities.

The primary goal of this project is to improve **task organization and time management** by providing a simple and user-friendly interface for managing tasks.

Users can add new tasks with details such as **task title, description, priority level, and due date**. The application also allows users to mark tasks as completed, edit existing tasks, and remove tasks that are no longer needed.

This project demonstrates core concepts of software development such as **CRUD operations (Create, Read, Update, Delete)**, data handling, and user interaction.

---

## 🚀 Features
- Add new tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- View all tasks in an organized list
- Simple and user-friendly interface
